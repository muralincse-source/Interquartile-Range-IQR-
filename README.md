# Interquartile Range (IQR) Analysis

## Overview
This project demonstrates how to calculate the **Interquartile Range (IQR)** using Python. IQR is a statistical measure used to understand the spread of data and identify potential outliers.

## Objectives
- Calculate Quartile 1 (Q1) and Quartile 3 (Q3).
- Compute the Interquartile Range (IQR).
- Detect outliers in a dataset.
- Visualize data distribution.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib

## Key Concepts
- **Q1 (First Quartile):** 25th percentile of the data.
- **Q3 (Third Quartile):** 75th percentile of the data.
- **IQR:** Difference between Q3 and Q1.

Formula:

```text
IQR = Q3 - Q1
